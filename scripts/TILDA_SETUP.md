# Инструкция по подключению скриптов на Tilda

## Файлы для подключения

1. **tilda-simple.js** - основной скрипт функционала меню
2. **dish-modal-styles.css** - стили для модального окна состава блюд

## Порядок подключения

### 1. Загрузить файлы на хостинг

Загрузите оба файла на ваш сервер:
- `https://fitbox.necodim.ru/scripts/tilda-simple.js`
- `https://fitbox.necodim.ru/scripts/dish-modal-styles.css`

### 2. Добавить на страницу Tilda

В настройках страницы Tilda → "Настройки" → "Еще" → "HTML-код для вставки внутри head":

```html
<!-- Стили модального окна -->
<link rel="stylesheet" href="https://fitbox.necodim.ru/scripts/dish-modal-styles.css">
```

В конец страницы (перед закрывающим `</body>`):

```html
<!-- Основной скрипт меню -->
<script src="https://fitbox.necodim.ru/scripts/tilda-simple.js"></script>
```

## Обновленные функции

### Карточка блюда
Теперь отображает:
- Название блюда
- КБЖУ на 100г в формате: "на 100 г: 112 ккал, 8/6/7 б/ж/у"
- Кнопка "Состав"

### Модальное окно
При клике на "Состав" открывается модальное окно с:
- Фото блюда (если есть)
- Полным списком ингредиентов с весом
- Детальной пищевой ценностью на 100г
- Общим весом блюда

Закрывается по:
- Клику на overlay (фон)
- Клику на крестик
- Нажатию Escape

## Проверка

После подключения:
1. Обновите страницу (Ctrl+Shift+R / Cmd+Shift+R)
2. Выберите программу питания
3. Должны увидеть КБЖУ вместо списка ингредиентов
4. Кнопка "Состав" должна открывать модальное окно
